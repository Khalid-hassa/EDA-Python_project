# Diwali Sales Analysis

Welcome to the Diwali Sales Analysis project! This repository contains an exploratory data analysis (EDA) of Diwali sales data using Python. The analysis aims to uncover insights into customer demographics, purchasing behaviors, and regional sales distributions during the Diwali festival period.

## Project Overview

The primary objectives of this project are:

1. **Data Exploration**: Utilize the Pandas library to load and examine the dataset, understanding its structure and contents.
2. **Data Visualization**: Employ various plotting techniques to visualize trends, patterns, and relationships within the data.

## Dataset Description

The dataset comprises over 10,000 records detailing customer purchases across various product categories throughout India during the Diwali festival. Key attributes include:

- **Gender**: Customer gender
- **Age Group**: Age bracket of the customer
- **State**: Customer's state of residence
- **Product Category**: Category of the purchased product
- **Amount**: Purchase amount

## Libraries Utilized

The analysis leverages the following Python libraries:

- **NumPy**: For numerical computations
- **Pandas**: For data manipulation and analysis
- **Matplotlib**: For basic plotting and visualization
- **Seaborn**: For enhanced statistical data visualization

## Analysis Highlights

The analysis encompasses several key areas:

- **Data Cleaning**: Addressing duplicates, setting appropriate indices, and adjusting data types as necessary.
- **Gender Distribution**: Analyzing the proportion of male and female customers.
- **Age Group Analysis**: Examining customer distribution across different age groups and their purchasing behaviors.
- **State-wise Sales**: Evaluating the total number of orders and sales amounts across various states.
- **Product Category Insights**: Investigating sales performance across different product categories.

## Repository Contents

- `Diwali Sales Data.csv`: The dataset used for analysis.
- `Diwali_Sales_Analysis.ipynb`: Jupyter Notebook containing the step-by-step exploratory data analysis.
- `README.md`: Project overview and documentation.

## Conclusion

This project provides a comprehensive exploratory analysis of Diwali sales data, offering insights into customer demographics and purchasing patterns. Such analyses can inform marketing strategies and business decisions during festive periods.
